# Proposal: Brainstorm Interrupt Icon

> 日期: 2026-05-02

## 为什么改

当前 brainstorm 发言中的 interrupt 采用右侧红色文字按钮，和输入区的工具按钮体系不一致，视觉上突兀，也削弱了 brainstorm 模式的统一性。

## 改什么

- 将 interrupt 操作改为输入工具组内的 icon button
- 放置在 brainstorm 闪电按钮旁边
- 使用“捂嘴”语义 icon，并沿用 brainstorm 紫色激活态
- 当 interrupt 已触发或当前不可用时，按钮保留但切换为灰色不可点击态

## 不改什么

- 不修改 brainstorm 后端协议和中断语义
- 不改发送按钮逻辑
- 不改 brainstorm 消息时间线与 divider 行为
