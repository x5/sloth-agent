# Release v0.5.4 — Brainstorm Engine + CI Quality Gates + Test Infrastructure

> Date: 2026-05-03
> Iter-4/5/6 Combined: Brainstorm Discussion Engine + Reply UI + Quality Pipeline

## Overview

v0.5.4 是桌面版最大一次功能迭代，横跨 Iter-4/5/6 三个迭代周期。核心交付：**Brainstorm 多轮讨论引擎**（从会话管理到流式 UI 全链路打通）、**CI 质量门禁体系**（diff-cover + 三层测试门禁 + pre-push hooks）、以及**前后端测试基础设施**全面铺开。

## Changes

### Brainstorm 多轮讨论引擎 (Iter-4)

- **Multi-round discussion engine**: 支持多轮 brainstorm 会话，每轮独立管理 agent 交互
- **Session CRUD**: 创建/列表/切换/结束 brainstorm session
- **Fluid chat UX**: brainstorm 模式下流式对话体验，支持 agent 自动轮流发言
- **Max messages limit**: 默认 1000 条消息上限，防止单 session 无限增长

### Brainstorm 连接持久化 + Reply UI (Iter-6)

- **Persistent SSE connection**: brainstorm session 保持长连接，断线自动重连
- **Reply UI**: 支持在 brainstorm 对话中回复特定消息
- **Thread colors**: 每个讨论线程分配独立颜色，视觉区分不同话题
- **Timeline dividers**: session 开始/结束时自动插入系统分隔消息
- **Interrupt 语义修复**: interrupt 只中断当前 round，不结束整个 session
- **Interrupt 按钮图标化**: 捂嘴语义 icon，与闪电按钮同组，点击后灰色不可再点
- **CoolingTimer**: agent 发言间自动冷却间隔，避免连续刷屏

### Brainstorm Session 状态逻辑 (Iter-5)

- **View vs. status 分离**: 切换 session 不再改变其 active/ended 状态
- **One-active-per-Inspiration**: 激活新 session 自动结束前一个
- **Lightning bolt toggle**: OFF 清除 view 不结束 session，ON 创建新 auto-active session
- **MessageResponse 字段补全**: 修复 brainstorm 消息响应缺少字段的问题
- **max_reached handler**: 消息上限到达时正确终止并提示

### Agent 状态管理增强

- **Agent status polling**: 1.2s 间隔自动轮询 agent 状态
- **Idle grace period**: 10 分钟宽限期，避免频繁状态闪烁
- **setAgentStatus action**: 前端可直接设置 agent 状态
- **Agent store 测试**: 新增 agentStore 单元测试

### CI 质量门禁体系

- **Diff-cover gate**: 新增/变更代码覆盖率门禁，阈值 90%
- **Backend unit test job**: CI 中独立后端单元测试任务
- **Three-layer test gate**: 文件级覆盖 → 集成测试 → diff-cover 三层把关
- **Pre-push hooks**: push 前自动运行后端 + 前端单元测试
- **Frontend lint auto-fix**: pre-commit 自动修复 ESLint 错误

### 测试基础设施

- **Integration test conftest**: 内存 SQLite + async session fixture
- **Backend integration tests**: brainstorm CRUD、agent templates、chat、inspirations、LLM 路由全覆盖
- **Frontend component tests**: ChatArea、BrainstormStreamBubble、RightPanel 等核心组件
- **AgentStore test**: 状态轮询、grace period、team 管理测试
- **BrainstormStore test**: session 生命周期、连接管理测试
- **ESLint v9 配置**: 前端升级 ESLint v9 + flat config

### DB 稳定性

- **WAL mode**: SQLite 切换为 WAL 模式，支持并发 SSE 读写
- **Busy timeout**: 设置 5s busy timeout，避免并发写入时报错
