# Release v0.5.3 — Brainstorm Status Logic + UI Polish

> Date: 2026-05-01
> Iter-3 Fix: Team Sidebar + Brainstorm UX + Design System Unification

## Overview

v0.5.3 fixes brainstorm session status logic, redesigns the Team Sidebar, and unifies UI patterns across the desktop app — custom tooltips, consistent avatars, and labeled status badges.

## Changes

### Brainstorm Session Status Logic

- **Separate view vs. status**: switching sessions no longer changes their active/ended status
- **Slide toggle** on session card: manual ON/OFF control for activating/deactivating sessions
- **One-active-per-Inspiration** enforcement: activating a session automatically ends the previous one
- **Lightning bolt toggle**: OFF now clears the view without ending the session; ON creates a new auto-active session
- **Transition dividers** in chat: "Session #A -> Session #B" when switching, guarded by brainstormMode

### Team Sidebar Redesign

- **Custom model dropdown**: replaced native `<select>` with animated popup matching design system
- **Icon add button**: replaced text "+Add" with unified 28x28 icon button (matches ProjectList/ProviderList)
- **Search in add-agent dropdown**: filter agents by name or role with auto-focus input
- **Dropdown animation fix**: resolved "jump" bug where popup appeared on right before centering
- **Divider lines restored**: add button keeps horizontal lines on both sides

### Agent Card Unification

- **Avatar shows team number** (1, 2, 3...) instead of first letter of name
- **Avatar size unified** with ProjectList: 32->36px, sans-serif font, `border-radius: var(--radius-sm)`
- **Status badge**: replaced bare colored dot with labeled pill ("Working"/"Idle") — green tint when active, gray when idle
- **Name font** increased from 13px/600 to 14px/500 for readability

### Custom Tooltip System

- **MUI-style tooltips** replace native browser `title` attribute across all buttons and icons
- **White/light theme**: white background, dark text, subtle border and shadow
- **3 position variants**: top (default), bottom (topbar buttons), right (sidebar nav)
- **Smooth animation**: 150ms fade-in with translate offset
- **Arrow pointer** with matching color and drop-shadow

### Design Consistency

- **rp-badge**: redesigned as subtle count indicator (muted text, neutral background, pill shape) — distinct from agent number badge
- **chat-message__avatar-num**: now uses role-based color (matching team sidebar avatar) instead of fixed accent color
- **Agent number + color mapping**: `agentColorMap` built from team members, passed through to chat messages

### DevOps

- **dev.sh**: one-command launcher script (backend + Tauri dev server)
- **Tauri config**: `beforeDevCommand` fixed for correct working directory
