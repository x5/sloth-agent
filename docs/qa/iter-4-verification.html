Task 4.0 — Models & SandboxManager
backend/app/models.py + backend/app/services/sandbox.py
1
BrainstormSession model — 14 columns + CHAR(36) PK
Tablename "brainstorm_sessions"。14 个 mapped_column：id, inspiration_id (FK), title, status, sandbox_path, max_messages, cooldown_seconds, message_count, summary, started_by, notification_sent, created_at, ended_at。
status default="active", max_messages default=500, cooldown_seconds default=5, message_count default=0。
2
BrainstormFile model — 7 columns
Tablename "brainstorm_files"。7 个 mapped_column：id, session_id (FK→brainstorm_sessions CASCADE), file_path, content, created_by (FK→inspiration_agents SET NULL), file_type, created_at。
file_type default="other"。content 为 Text 类型。
3
SandboxManager.create_session_dir() — sandbox at project root
创建 brainstorm-sessions/{session_id}/ 目录。
路径在项目根目录（不是 backend/ 子目录）。使用 _PROJECT_ROOT 计算。
返回绝对路径。
4
SandboxManager.get_file_tree() — recursive listing
递归遍历 sandbox 目录，返回 [{name, path, type, size}]。
type 为 "file" 或 "directory"。path 使用 "/" 分隔符。
目录在前、文件在后，各自按字母排序。空目录返回 []。
5
SandboxManager.archive_session() + cleanup_archive()
archive_session: 将会话目录移动到 .archive/{session_id}-{timestamp}/。
cleanup_archive(max_age_days=7): 删除 7 天前的归档目录。
会话目录不存在时 archive_session 静默返回。
6
.gitignore — brainstorm-sessions/ + sloth.db
.gitignore 包含 brainstorm-sessions/ 和 backend/sloth.db。
sandbox 目录和 SQLite 数据库不会被提交到 Git。
Task 4.1 — Brainstorm CRUD API (brainstorm.py)
backend/app/routers/brainstorm.py — 4 endpoints: create / list / get / update
7
POST /api/inspirations/{id}/brainstorm-sessions — 创建会话
请求体 {"title": "..."} → 验证：min_length=1, max_length=200。
Inspiration 不存在 → 404。
创建 BrainstormSession DB 行 → 创建 sandbox 目录 → 更新 sandbox_path → 返回 201。
返回含 file_tree（初始为空数组 []）。
8
GET /api/inspirations/{id}/brainstorm-sessions — 列表
返回该 Inspiration 下所有会话，按 created_at DESC 排序。
Inspiration 不存在 → 404。
每个会话含 file_tree。空列表返回 []。
9
GET /api/brainstorm-sessions/{id} — 详情
返回单个会话完整数据（15 字段含 file_tree）。
会话不存在 → 404。
10
PATCH /api/brainstorm-sessions/{id} — 更新
部分更新 title 和/或 status。
status 仅接受 "active"|"cooling_down"|"ended"|"summarized"。
status="ended" 时自动设置 ended_at = now()。
会话不存在 → 404。
11
main.py — brainstorm router 注册
app.include_router(brainstorm.router) 在 main.py 中。
/api/inspirations/{id}/brainstorm-sessions 和 /api/brainstorm-sessions/{id} 可访问。
