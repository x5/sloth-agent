Task 3.1 — Team Management API (agents.py)
backend/app/routers/agents.py — 4 endpoints: list / add / update / remove
9
GET /api/inspirations/{id}/agents — Agent 列表
返回 Inspiration 下所有 Agent（按 joined_at 升序）。
每个 Agent 含：id, name, role, model, status, template_id, joined_at。
role 从 AgentTemplate 解析，非硬编码。
10
POST /api/inspirations/{id}/agents — 添加 Agent
从 AgentTemplate 拉入 Team：name/model 继承模板。
状态初始 "idle"。返回 201。
同一 template 重复添加 → 409 Conflict。
11
PATCH /api/agents/{id} — 更新 Agent 模型
修改 Agent 的 model 字段。部分更新（仅 model）。
Agent 不存在 → 404。
12
DELETE /api/inspirations/{id}/agents/{agentId} — 移除 Agent
非 Lead Agent 可移除 → 204。
Lead Agent 移除 → 403 "Cannot remove Lead Agent from team"。
Agent 不属于该 Inspiration → 404。
13
创建 Inspiration → Lead Agent 自动加入
POST /api/inspirations → join_auto_agents() → Lead Agent (role=lead, auto_join=true) 自动添加。
返回的 InspirationResponse 中 agent_count = 1（修复之前返回 0 的 bug）。
Expert agent (auto_join=false) 不会自动加入。
14
Agent status 模型 — idle / working / error
InspirationAgent 创建时 status 默认为 "idle"。
DB 字段：String(20)，default="idle"。状态值合法且持久化正确。
